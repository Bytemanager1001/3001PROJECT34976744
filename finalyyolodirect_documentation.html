1. Project overview

This script prepares a labelled image dataset for YOLO object detection, trains a YOLOv8 nano model, evaluates the trained model on a test split, saves annotated prediction images, and calculates additional defect-level and package-level results.

Detection classes

Loose meat, twisted meat, unsealed packaging, and wrinkle.

Model

YOLO("yolov8n.pt"), trained with a maximum of 50 epochs, image size 640, batch size 16, and patience 10.

Annotation input

CSV rows containing image filenames, image dimensions, class names, and bounding-box coordinates.

Output

YOLO dataset files, a YAML configuration, trained weights, test metrics, prediction images, and package-level statistics.

2. Execution workflow

  1. Mount Google Drive and import required libraries.
  2. Set dataset, output, and model-run paths.
  3. Define defect class names and aliases that map CSV labels to integer class IDs.
  4. Find each split's CSV annotation file and validate required columns.
  5. Group bounding boxes by image and create a training/validation split from the annotated training images.
  6. Copy images into a YOLO directory structure and write normalised YOLO label text files.
  7. Write data.yaml with train, validation, test paths and class names.
  8. Train YOLOv8n and load the resulting best.pt weights.
  9. Evaluate the model on the test split and print precision, recall, mAP@50 and mAP@50–95.
  10. Save test-image predictions and calculate per-class recall and package-level faulty/error-free accuracy.

3. Configuration and class mapping

  • BASE_DIR: Google Drive project directory, /content/drive/MyDrive/Colab Notebooks/3001.
  • TRAIN_DIR: source training folder.
  • TEST_DIR: source test folder.
  • YOLO_DATASET: generated dataset root, /content/yolo_dataset.
  • RUNS_DIR: training/evaluation output directory, yolo_original_results under the project folder.
  • IMAGE_EXTS: accepted source image extensions include JPG, JPEG, PNG, BMP and WEBP.

The class IDs are: 0 = loose-meat, 1 = twisted-meat, 2 = unsealed, and 3 = wrinkle. CLASS_ALIASES accepts several alternative CSV label spellings.

5. Evaluation metrics

  • Precision: proportion of predicted detections that are correct under the evaluation matching rules.
  • Recall: proportion of annotated defect instances detected by the model.
  • mAP@50: mean Average Precision at IoU threshold 0.50.
  • mAP@50–95: mean Average Precision averaged across IoU thresholds from 0.50 to 0.95.
  • Per-class recall: recall reported for each defect category when that class has evaluated test instances.
  • Package-level accuracy: percentage of evaluated images where the predicted faulty/error-free status matches the status derived from annotations.

6. Implementation notes and checks

Validation-split detail: the script creates the validation split from the annotated images in TRAIN_DIR; it does not use a separate valid folder in the conversion calls shown in this source.
  • The script deletes the existing /content/yolo_dataset directory before rebuilding it.
  • The CSV must have exactly the expected annotation columns, including filename, width, height, class, xmin, ymin, xmax, and ymax.
  • The package-level calculation treats images without a CSV annotation row as error-free. This is only valid if the CSV represents all faulty test images and unannotated images truly are defect-free.
  • The package-level evaluation image list currently includes JPG, JPEG and PNG files directly inside the test directory; nested images and BMP/WEBP files are not included in that particular list.
  • Class-level recall and AP are different measures. The per-class section prints recall, while the standard YOLO evaluation also provides per-class AP data.
  • Generated HTML documentation describes the uploaded source; it does not confirm that the code runs successfully in the user's Colab environment.

IMAGE_EXTS = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}

def find_csv(folder):
    """Finds the single CSV file in a given directory.

    Args:
        folder (Path): The directory to search for a CSV file.

    Returns:
        Path: The path to the found CSV file.

    Raises:
        ValueError: If there is not exactly one CSV file in the directory.
    """
    csvs = list(folder.glob("*.csv"))
    if len(csvs) != 1:
        raise ValueError(
            f"Expected exactly one CSV in {folder}, found: {[p.name for p in csvs]}"
        )
    return csvs[0]

def convert_split(source_dir, split_name, csv_path=None):
    """Converts annotations from a source directory CSV structure into YOLO format.

    Args:
        source_dir (Path): The directory containing the source images and CSV file.
        split_name (str): The name of the split ('train' or 'test').
        csv_path (Path, optional): Path to the CSV file. If None, it will be searched in source_dir.

    Returns:
        None
    """
    csv_path = csv_path or find_csv(source_dir)
    df = pd.read_csv(csv_path)

    required = {
        "filename", "width", "height", "class",
        "xmin", "ymin", "xmax", "ymax"
    }
    missing = required - set(df.columns)
    if missing:
        raise ValueError(f"Missing CSV columns in {csv_path.name}: {missing}")

    # Look up image files by filename.
    image_lookup = {
        p.name: p for p in source_dir.rglob("*")
        if p.is_file() and p.suffix.lower() in IMAGE_EXTS
    }

    # Group all bounding boxes belonging to each image.
    grouped = {
        str(name): group
        for name, group in df.groupby("filename")
    }

    # Keep annotated images together when making a validation split.
    filenames = sorted(grouped.keys())
    random.Random(42).shuffle(filenames)

    if split_name == "train":
        if len(filenames) < 2:
            raise ValueError("Need at least two annotated training images.")
        n_val = max(1, round(0.2 * len(filenames)))
        val_names = set(filenames[:n_val])
        train_names = set(filenames[n_val:])
        assignments = [
            ("train", train_names),
            ("val", val_names)
        ]
    else:
        assignments = [(split_name, set(filenames))]

    for target_split, names in assignments:
        img_out = YOLO_DATASET / "images" / target_split
        lbl_out = YOLO_DATASET / "labels" / target_split
        img_out.mkdir(parents=True, exist_ok=True)
        lbl_out.mkdir(parents=True, exist_ok=True)

        for filename in names:
            if filename not in image_lookup:
                print(f"WARNING: Image not found, skipping: {filename}")
                continue

            group = grouped[filename]
            src = image_lookup[filename]
            dst = img_out / src.name
            shutil.copy2(src, dst)

            # Write one YOLO label file per image.
            lines = []
            for _, row in group.iterrows():
                raw_class = str(row["class"]).strip().lower()
                if raw_class not in CLASS_ALIASES:
                    raise ValueError(
                        f"Unknown class '{row['class']}' in {csv_path.name}. "
                        "Add it to CLASS_ALIASES."
                    )

                class_id = CLASS_ALIASES[raw_class]
                width = float(row["width"])
                height = float(row["height"])

                xmin = float(row["xmin"])
                ymin = float(row["ymin"])
                xmax = float(row["xmax"])
                ymax = float(row["ymax"])

                if width <= 0 or height <= 0:
                    raise ValueError(f"Invalid image dimensions for {filename}")

                # YOLO uses normalised centre coordinates and box dimensions.
                x_center = ((xmin + xmax) / 2) / width
                y_center = ((ymin + ymax) / 2) / height
                box_width = (xmax - xmin) / width
                box_height = (ymax - ymin) / height

                # Check coordinates are valid.
                if not (0 <= x_center <= 1 and 0 <= y_center <= 1
                        and 0 < box_width <= 1 and 0 < box_height <= 1):
                    raise ValueError(
                        f"Invalid bounding box in {filename}: "
                        f"{xmin, ymin, xmax, ymax}"
                    )

                lines.append(
                     f"{class_id} {x_center:.6f} {y_center:.6f} "
                     f"{box_width:.6f} {box_height:.6f}"
                )

            (lbl_out / f"{src.stem}.txt").write_text(
                "\n".join(lines), encoding="utf-8"
            )

    print(f"Converted annotations from {csv_path}")

# Ground truth:
#   Faulty     = CSV contains at least one defect annotation
#   Error-free = CSV has no defect annotation for that image
#
# Prediction:
#   Faulty     = YOLO predicts at least one defect above threshold
#   Error-free = YOLO predicts no defects above threshold
#
# Note: TEST_DIR contains the original test images and

def find_csv(folder):
    csv_files = list(folder.glob("*.csv"))

    if len(csv_files) != 1:
        raise ValueError(
            f"Expected one CSV in {folder}, found {len(csv_files)}"
        )

    return csv_files[0]

csv_path = find_csv(TEST_DIR)
df = pd.read_csv(csv_path)

required_columns = {"filename", "class"}
if not required_columns.issubset(df.columns):
    raise ValueError(f"CSV must contain {required_columns}")

# An image is faulty if it has one or more annotated defects.
df["image_name"] = df["filename"].astype(str).map(
    lambda x: Path(x.strip()).name.lower()
)

ground_truth = (
    df.groupby("image_name")["class"]
    .apply(lambda classes: classes.notna().any())
    .to_dict()
)

# Include error-free images in the test set.
# Images with no CSV annotation row are treated as error-free,
# so the CSV must represent all test images for this to be valid.
test_images = [
    p for p in TEST_DIR.iterdir()
    if p.is_file() and p.suffix.lower() in {".jpg", ".jpeg", ".png"}
]

correct = 0
tp_faulty = 0
tn_error_free = 0
fp_error_free = 0
fn_faulty = 0
evaluated = 0

for image_path in test_images:
    image_name = image_path.name.lower()

    # Ground-truth package status
    actual_faulty = ground_truth.get(image_name, False)

    # Predict defects in the image

    results = best_model.predict(
        source=str(image_path),
        conf=CONF_THRESHOLD,
        verbose=False
    )

    predicted_faulty = (
        results[0].boxes is not None
        and len(results[0].boxes) > 0
    )

    evaluated += 1

    if actual_faulty == predicted_faulty:
        correct += 1

    if actual_faulty and predicted_faulty:
        tp_faulty += 1
    elif not actual_faulty and not predicted_faulty:
        tn_error_free += 1
    elif not actual_faulty and predicted_faulty:
        fp_error_free += 1
    else:
        fn_faulty += 1

if evaluated > 0:
